Step 3 of 6

Three ways to answer it

We looked at three ways to answer the question. Each gets something right. Here is what each one is, what it gets right, and where it falls short.

  1. 1

    Build another map

    not enough on its own

    Gather today's public data into one new map showing who needs help, the hazards and the shelters.

    What it gets right

    Planners need to see places, and DHS asks for exactly this map. We draw one too.

    The catch

    A map is only as current as what feeds it. Hawaiʻi already has shelter maps that went stale (one is dated 2012). A new map copies the same blank, undated facts and goes stale too.

    Full reasoning

    Gather today's public data into one new map or dashboard that shows AFN, hazards and shelters together.

    Gets right: It answers a pain point the brief names in so many words, and planners need to see places. Our own entry draws a map too; a map is a good thing to have.

    Catch: A map is only as current as what feeds it. Without a label saying who owns each layer and when it was last confirmed, a new map copies today's stale and blank fields into a nicer picture, and goes stale itself once the team that built it moves on. Hawaiʻi already has several shelter maps that did exactly that. The brief asks for a framework that can be maintained after the challenge.

    “Feasibility: the framework can operate within existing IT infrastructure and be maintained after the challenge.”

    DHS challenge brief, p. 7
    Show the evidence (1)
    • Shelter maps that went stale: the State open-data list ("Date Updated: June 18, 2012"), the Pacific Disaster Center layer (content dated 2009), an Esri tutorial copy (last edited 2014-06-27), a retired Honolulu layer that now returns an error, and a Honolulu "DRAFT Veoci to ArcGIS Integration for Shelters" layer that still shows test sites as "Open" (last edited 2022-10-26). source, checked 2026-11-14
  2. 2

    Make everyone use one system

    rejected as the first step

    One statewide system, or one strict data standard, that every agency, nonprofit and utility must enter its data into.

    What it gets right

    Shared words and one place to look are exactly what's missing.

    The catch

    For shelters, that system already exists: FEMA's, updated daily with the Red Cross. Most of its Hawaiʻi records leave the generator box blank. A system doesn't fill itself, and a mandate makes everyone pay before anyone benefits.

    Full reasoning

    Stand up one statewide platform (or mandate one detailed data standard) that every county, State program, nonprofit, utility and health partner enters its data into.

    Gets right: Shared words and one place to look are exactly what is missing, and the State has a legal home for format standards. A single system would also give the State the roll-up it lacks.

    Catch: For shelters, that shared system already exists (FEMA's ESF#6 Shelter System, synced daily with the Red Cross) and its key boxes are empty: a system does not fill itself. A mandate also runs into the brief's own limits: no system holds all the data, the plan must sit alongside county plans rather than replace them, data-sharing agreements are already a listed burden, and State data guidelines are 'strongly recommended', not binding. Maui withholds its list for a safety reason that a mandate does not answer. It asks every sector to pay the full cost before anyone gets any benefit.

    “No single system includes the universe of data; DHS does not serve all individuals and households with AFN in Hawaiʻi.”

    DHS challenge brief, p. 5
    Show the evidence (3)
    • FEMA's ESF#6 Shelter System is "synchronized every morning with the American Red Cross shelter database", yet on Hawaiʻi's 729 records `generator_onsite` is blank or null on 554 and the four counties are spelled 9 ways. source, checked 2026-11-14
    • HRS §27-44.3 gives the Chief Data Officer the job of "data set format standards to be used by all agencies", but the CDO guidelines we read each say "Compliance is strongly recommended". source, checked 2026-11-14
    • MEMA's reason for not publishing: "When frightened people were calling from community centers that weren't open, as tropical storm force winds were hitting, they realized that the published list was putting people into harm's way." source, checked 2026-11-14
  3. 3

    Label what exists, then improve it step by step

    chosen

    Leave each source where it is. Describe every one the same way, with a label. Then help each owner share it a little better, one step at a time.

    What it gets right

    It starts from what partners already keep, costs an owner a spreadsheet rather than a new system, and is honest about what is still a phone call.

    Why we chose it

    Each step is useful even if the next never comes, so nothing waits on a statewide deal. It turns “the information exists” into a list of who holds what, and what to ask them.

    Full reasoning

    Put the same one-page label on every source (owner, what it covers, area level, unit, last confirmed, how to get it, privacy level, limits). Leave each source where it is. Each sector climbs from level 0 (a phone call) to level 3 (a service that answers with counts per area) at its own pace. From public data, build the map and a printable brief per county and hazard today; every gap names who to ask.

    Gets right: It starts from what each partner already keeps, costs a sector a spreadsheet rather than a new system, is honest about what is still a phone call, and works alongside county plans and existing systems (a FEMA or county map service is simply labeled at the rung it already stands on). The words come from standards that already exist (DCAT-US, HSDS, NSS, NIMS), so nothing new has to be invented or bought.

    Why: Each rung is useful even if the next never comes, so progress does not wait on a statewide agreement. It turns 'the information exists' into a list of who holds what and what to ask, which is the step the brief says is done by hand every event. Its weakness is that it depends on owners choosing to climb; the stages below put the cheapest rung first and name who could own the shared words.

    “Manual steps: Pulling program and provider reports, cross-referencing lists with hazard zones, contacting partners (phone, text, email) to confirm shelter, transport, staffing, and supply capacity.”

    DHS challenge brief, p. 3
    Show the evidence (3)
    • The State already asks for labels: CDO-003 Data Catalog Guidelines (28 August 2025) say each agency should keep a catalog and metadata for its data assets and name a data steward for each. Both State portals already publish DCAT-US records with owner, contact, address and last-changed date on every dataset. source, checked 2026-11-14
    • Ladders and thin standards have worked elsewhere: the 5-star open data scheme lets a publisher stop at any step; GTFS "started with a collaboration between TriMet in Portland, Oregon, and Google" and now reports "over 10,000 agencies in 100+ countries". source, checked 2026-11-14
    • A level-3 source for people already exists and protects privacy: HHS emPOWER answers with counts per ZIP and masks 1 to 10 as 11. source, checked 2026-11-14
